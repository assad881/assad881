# كسارة اكسبريس — Express Crusher

تطبيق ويب لإدارة أعمال الكسارة: تسجيل النقلات، أسعار المواد، حسابات العملاء والذمم،
المصروفات التشغيلية، سندات التسليم والقبض، والتقارير.

يعمل بالكامل داخل المتصفح — **بدون خادم، وبدون إنترنت، وبدون أي اعتماديات خارجية**.
كل البيانات تُحفظ محليًا في `localStorage` على جهازك.

---

## التشغيل

**الأسهل:** افتح `index.html` مباشرة في المتصفح.

**أو ملف واحد مستقل:** `dist/express-crusher.html` — انسخه على الجوال أو الكمبيوتر وافتحه، يعمل بالكامل.

**أو عبر خادم محلي:**

```bash
python3 -m http.server 8080
# ثم افتح http://localhost:8080/crusher/
```

**إعادة بناء الحزمة المفردة بعد أي تعديل:**

```bash
python3 crusher/build.py
```

## البداية السريعة

1. الإعدادات ← **تحميل بيانات تجريبية** لرؤية التطبيق وهو يعمل (عملاء، نقلات، مدفوعات، مصروفات).
2. الإعدادات ← **بيانات المؤسسة**: الاسم والهاتف والسجل التجاري والرقم الضريبي — تظهر في كل مستند مطبوع.
3. الإعدادات ← **حذف كل البيانات** عندما تريد البدء ببياناتك الحقيقية.

## الشاشات

| الشاشة | الوظيفة |
|---|---|
| **اليوم** | نقلات اليوم وكمياتها، الإيراد والمحصّل، إيراد الشهر ومصروفاته وصافيه، الإيراد اليومي لآخر 30 يومًا، أكبر العملاء وأعلى المديونيات |
| **النقلات** | سجل كل نقلة: العميل، المادة، الكمية والوحدة، سعر الوحدة، الخصم، الشاحنة والسائق، الموقع، نقدي/آجل — مع تصفية بالتاريخ والعميل والمادة، وتصدير CSV، وسند تسليم لكل نقلة |
| **العملاء** | أرصدة الذمم لكل عميل، أعمار الذمم، كشف حساب تفصيلي قابل للطباعة، وأسعار خاصة لكل عميل |
| **المدفوعات** | الدفعات المحصّلة (نقد / تحويل / شيك) مع سند قبض مطبوع ومبلغ مكتوب بالحروف |
| **المواد والأسعار** | قائمة الأسعار الافتراضية لكل مادة ووحدتها، والكمية المبيعة وإيرادها خلال الشهر |
| **الشاحنات** | الشاحنات والسائقون، عدد النقلات والكميات المنقولة والإيراد والمصروف لكل شاحنة |
| **المصروفات** | الديزل والصيانة وقطع الغيار والرواتب والإيجارات والتفجير والكهرباء — مع توزيعها ونسبتها من الإيراد |
| **التقارير** | ملخص الفترة، الإيراد مقابل المصروف، التحليل حسب المادة والعميل والشاحنة والشهر، أعمار الذمم، وتقرير مطبوع كامل |
| **الإعدادات** | بيانات المؤسسة، ضريبة القيمة المضافة، اللغة والمظهر، النسخ الاحتياطي والاستيراد |

## قاعدة الحساب

```
النقلة النقدية  →  إيراد + تحصيل فوري (لا تدخل الذمم)
النقلة الآجلة   →  إيراد + مدين على العميل (تدخل الذمم)
الدفعة          →  تحصيل، ويُسدَّد به أقدم آجل أولًا (FIFO)

رصيد العميل = الرصيد الافتتاحي + مجموع النقلات الآجلة − مجموع الدفعات
صافي الربح   = إجمالي الإيراد − إجمالي المصروفات
```

العملة الريال العماني بثلاث خانات عشرية (1 ر.ع = 1000 بيسة).
ضريبة القيمة المضافة اختيارية وتُضاف على المستندات المطبوعة عند تفعيلها من الإعدادات.

## المستندات المطبوعة

سند تسليم مواد · سند قبض · كشف حساب عميل · تقرير الفترة —
كلها بترويسة المؤسسة وخانات التوقيع، والمبلغ مكتوب بالحروف بالعربية، بمقاس A4.

## البيانات والنسخ الاحتياطي

كل شيء في `localStorage` داخل متصفحك فقط، ولا يُرسل إلى أي خادم.

- **نسخة احتياطية:** الإعدادات ← تصدير جميع البيانات (JSON).
- **استعادة:** الإعدادات ← استيراد نسخة.
- مسح بيانات المتصفح لهذا الموقع يمسح كل شيء، لذا صدّر نسخة بين حين وآخر.

  dist/                    حزمة بملف واحد
